# QUIX

# Description

### QUIX is a simple quiz generator website where you can conduct quiz competition of different genre and topic , challenge your own knowledge with quiz generator and play quiz with your friends. It is very simple and fun to use. It has multiple mods such as:
- Normal Generator: It can be used to generate normal questions and test your skill at your own.
- Competition mode: Here, you can invite a friend and compete against him in pass and play, and have fun together.
- xGuess: xGuess is a football guessing ver of quix where you have to guess the football player from the clues, you will get 3 lives and your points will be tracked acc to the clues needed to answer.

## Technology Stack
- Node.js
- Express.js
- Html
- Css
- Javascript

## Features
- Quiz Generation
- Quiz Competition
- xGuess (Football Guesser)
- Custom clicking sound
- Absolute masterpiece in User interface
- Easy to use
- Different category of quiz
