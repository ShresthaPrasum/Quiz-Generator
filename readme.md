# QUIX

# Description

### QUIX is a simple quiz generator website where you can conduct quiz competition of different genre and topic , challenge your own knowledge with quiz generator and play quiz with your friends. It is very simple and fun to use.

## Technology Stack
- Node.js
- Html
- Css
- Javascript

## Features
- Quiz Generation
- Quiz Competition
- Text to speech
- Custom clicking sound
- Absolute masterpiece in User interface
- Easy to use
- Different category of quiz
