About xGuess

xGuess is a web application which is used to guess the football players from 2-3 clues. YOU have to enter some details and clues will generate then you can start guessing and then you need to guess the player with the input box given below the clues!!! (this is a web application made for having fun, and especially for football fans to test their ball knowledge yk). Also you need to name the player's FULL EXACT NAME, it should be same as in our data else you are gonna be wrong in the charge of speeling error.
